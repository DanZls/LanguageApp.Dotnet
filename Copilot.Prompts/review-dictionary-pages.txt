Resources\Processed\DictionaryRuBgFrequencyPages contains page files with ru-bg translations. The translations look like "[word index number]|[word in russian]|[word meaning]|[word in bulgarian]|[linguistic tags]" with [linguistic tags] related to [word in bulgarian].
However, the translations may contain errors such as: 
- incorrect linguistic tags
- missing meaning/translation/tags
- linguistic tags not separated by ";"
- wrong symbols
- mistakes in translations
- all letters in lower case for personal names (can occur in a word and its translation)
Also, several different mistakes may be present at once.

Please perform the following procedure for pages 0-50:
- read page files completely and check them for mistakes, fix any mistakes found
- process the files in batches of 5
- analyze files in a batch together, but edit each file separately to avoid hitting the output length limit
- after each batch, output to the end of log.txt the lines changed in each file of the batch as "[old line]-[new line]"
- move to the next batch only when the work with the current one is completed

Notes:
- do not use any scripts for this job, do the work yourself with your own knowledge
- adjectives are masculine by default, so it is not mentioned explicitly - this is not a mistake
- no need to output the edited lines to the chat as well, the log output is sufficient
